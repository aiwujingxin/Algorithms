## Key Findings

- **二进制原子论核心命题**：2的幂次（1, 2, 4, 8, ...）是OR运算空间的"原子"——它们只能由自身生成，不能被其他数字的OR组合产生。这一命题是LeetCode 2568算法正确性的数学基石，也是连接7道经典题目的第一块砖。
- **连续性不变量统一三类问题**：加法空间（LC 128、1798、330）、OR空间（LC 2568、338）与MEX空间（LC 41）表面语法不同，但共享同一个"前缀可达性"不变量`reach`：只要当前集合中存在一个元素 ≤ reach+1，可达集就能无缝扩张；否则连续性断裂。
- **降维元定理**：运算的单调性（OR或加法）× 连续性不变量 = 将指数级暴力搜索压缩至线性或对数线性的算法。这是7道题全部能在O(n log M)以内求解的统一原因。
- **OR空间与加法空间不同构但在幂次基上等价**：当生成集恰好是2的幂次集合时，OR-closure与Σ-closure重合；但对一般集合（如{3,5}），二者严格不等。统一框架是"有序幺半群上的单调覆盖扩展引理"，而非完全同构。
- **3133题是2568的对偶**：2568寻找OR不可达的最小正整数（缺失原子探测），3133在AND约束下构造最小可达终点（bit交织逆向构造）。二者共同刻画了OR宇宙的"边界"与"中心"，形成完整的对偶图景。

## 引言：算法的尽头是数学

有这样一类算法题，初看像是离散的谜题——有的让你找数组里第一个缺失的正整数，有的让你统计二进制位中1的数量，有的让你在最少次添加后覆盖从1到n的所有整数。它们散落在LeetCode的各个难度区间，表面上毫无关联：不同的数据结构，不同的操作语义，不同的解题技巧。

然而，当你把目光从"如何写代码"转向"为什么这样做是对的"，一幅统一的图景便从迷雾中浮现：**这七道题背后，只有一个数学内核。**

这个内核可以用一句话概括：**在满足单调性的运算空间中，前缀可达集的连续性由一个叫reach的不变量守护；守护失败之处，即是答案所在。**

LeetCode 2568（Minimum Impossible OR）是打开这扇门的钥匙。它问的是：给定一个正整数集合，最小的无法被任何子集OR得到的正整数是什么？这道题的答案如此简洁——依次检查1, 2, 4, 8, ...——以至于第一次看到时容易错过它的深刻。但正是这道题，将二进制原子论与连续性统一场论联结在一起，成为贯穿7道题的叙事主线。

本报告将以2568为基石，系统阐述**二进制原子论**与**连续性统一场论**，严格证明三个关键命题，并最终给出一个覆盖7道LeetCode经典题目的统一数学框架——不是代码层面的相似，而是数学结构的同构。

## 第一章：二进制原子论 — OR宇宙的基本粒子

### 1.1 原子的隐喻

19世纪化学家门捷列夫的元素周期表揭示了一个惊人的事实：万千物质由百余种元素构成，而元素之间存在深刻的规律性。在算法的OR宇宙中，存在类似的"元素周期表"：**2的幂次集合 {1, 2, 4, 8, 16, ...}**。

为什么是这些数字？答案来自OR运算最深刻的性质：**单调性与幂等性**。

OR运算是**单调的**：对任意整数集合S和额外元素x，`OR(S ∪ {x}) ≥ OR(S)`。一旦某个二进制位被"点亮"，它永远不会再熄灭——OR只能设位，不能清位。这便是**OR单向传染性**：信息只能增加，不能减少。

OR运算是**幂等的**：`x | x = x`。将一个数与自身OR，结果不变。这与加法截然不同（`x + x = 2x`），也正是OR空间与加法空间代数结构根本差异的来源。

### 1.2 命题1：OR唯一生成引理

**命题（OR唯一生成引理）**：设S为正整数集合，k为非负整数。则 `2^k` 可被S的某个子集OR得到，当且仅当 `2^k ∈ S`。

**证明**：

必要性显然：若`2^k ∈ S`，则`{2^k}`本身是一个子集，其OR值即为`2^k`。

充分性：假设`2^k ∉ S`，需证明S的任意子集的OR值不等于`2^k`。

S中每个元素`s`在第k个二进制位上的取值有两种情况：
- 若`s`的第k位为0，则`s`对第k位无贡献；
- 若`s`的第k位为1，则`s ≥ 2^k`，且因为`s ≠ 2^k`（已假设），故`s`在某个高于k的位或低于k的位还有其他1-bit。

若取任意子集T：若T中没有第k位为1的元素，则`OR(T)`的第k位为0，不等于`2^k`；若T中有第k位为1的元素t，则`t > 2^k`（因为t拥有额外的1-bit），故`OR(T) ≥ t > 2^k`，也不等于`2^k`。

因此，`2^k`无法由不含`2^k`的集合的任何子集OR得到。命题得证。 ∎

这个引理的意义是深远的：**2的幂次在OR运算下是"原子"**——它们无法由其他元素合成，只能作为"基本粒子"直接存在于集合中。

### 1.3 LeetCode 2568：寻找缺失的原子

> **题目**：给定正整数数组`nums`，返回最小的正整数，使得该整数无法由`nums`的任何子集的OR得到。

由唯一生成引理，答案的寻找策略极为简洁：依次检查 `1, 2, 4, 8, ...`，找到第一个不在`nums`中的2的幂次，即为答案。

```python
def minImpossibleOR(nums: list[int]) -> int:
    s = set(nums)
    x = 1
    while x in s:
        x <<= 1  # x = x * 2
    return x
```

**复杂度**：时间O(n + log M)，其中M为nums中最大值；空间O(n)用于哈希集合。

算法的精妙之处在于：我们完全不需要枚举指数级别的子集组合。唯一生成引理将问题从"检查所有2^n个子集"压缩到"检查O(log M)个候选原子"。这正是第五章将阐述的**降维打击**的第一个实例。

### 1.4 LeetCode 338：计数原子的镜像

> **题目**：对于 `0` 到 `n` 中的每个整数，计算其二进制表示中1的个数。

338与2568形成了一对精妙的"**解构-探测**"镜像：
- **2568**：从OR空间的宏观可达集出发，向下"探测"哪个原子（2的幂次）缺失；
- **338**：从每个整数出发，向下"解构"它由哪些原子（2的幂次bit位）组成。

338的核心递推：`popcount(n) = popcount(n >> 1) + (n & 1)`。每个整数n的popcount等于n右移一位（去掉最低位）的popcount，加上最低位是否为1。

```python
def countBits(n: int) -> list[int]:
    dp = [0] * (n + 1)
    for i in range(1, n + 1):
        dp[i] = dp[i >> 1] + (i & 1)
    return dp
```

两题合在一起，描述了同一个OR原子宇宙的两个互补视角：一个统计已有的原子，一个寻找缺失的原子。

## 第二章：连续性探测 — 从OR空间到加法空间

### 2.1 reach不变量的引入

在理解了OR空间的原子论之后，我们转向一个更宏观的问题：给定一个数字集合，它能"覆盖"的值域有多大？

这里的"覆盖"在不同空间有不同含义：
- **加法空间**：能否用子集之和表示从0到某整数的所有值？
- **OR空间**：能否用子集之OR表示从0到某整数的所有值（含OR组合）？

两个空间的核心分析工具是同一个——**reach不变量**：`reach`表示"目前已确认可以覆盖`[0, reach]`（或`[1, reach]`）中所有整数"。

**前缀可达性定理（Brown准则的算法版）**：

设已排序的正整数序列`a_1 ≤ a_2 ≤ ... ≤ a_m`，维护不变量`reach`（初始为0）。依次处理每个元素：
- 若`a_i ≤ reach + 1`：则`reach`更新为`reach + a_i`（加法空间）或`reach | a_i`（OR空间）；
- 若`a_i > reach + 1`：连续性断裂，`reach + 1`即为第一个不可达整数。

这一定理在加法空间有严格的完整性证明（Brown准则，基于数论级数收敛性），在OR空间则由原子唯一生成引理直接导出。

```
┌─────────────────────────────────────────────────────────────┐
│                  reach 不变量扩展流程                         │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│   初始化: reach = 0, 排序集合 S                              │
│              │                                              │
│              ▼                                              │
│   ┌─── 取下一个元素 s_i ───┐                                │
│   │                        │                               │
│   │   s_i ≤ reach + 1 ?    │                               │
│   │                        │                               │
│   ├── YES ──┐    ┌── NO ──┤                               │
│   │         │    │         │                               │
│   │    ┌────▼────▼───┐    │                               │
│   │    │ 加法空间:    │    │    连续性断裂!                  │
│   │    │ reach += s_i │    │    答案 = reach + 1            │
│   │    ├─────────────┤    │                               │
│   │    │ OR空间:      │    │                               │
│   │    │ reach |= s_i │    │                               │
│   │    └──────┬──────┘    │                               │
│   │           │           │                               │
│   │           ▼           │                               │
│   │     还有元素？         │                               │
│   │      │         │      │                               │
│   │     YES → 循环  NO → reach 即为最大覆盖                │
│   └─────────────────────────────────────────────────────┘  │
└─────────────────────────────────────────────────────────────┘
```

### 2.2 LeetCode 1798：加法空间的2568

> **题目**：给定硬币数组`coins`，问从0开始能连续"做出"的最大整数是多少（即最大的reach）。

这正是加法空间版的2568：2568在OR空间寻找第一个缺口（不可达原子），1798在加法空间寻找最大的连续前缀覆盖范围。

```python
def getMaximumConsecutive(coins: list[int]) -> int:
    coins.sort()
    reach = 0
    for coin in coins:
        if coin > reach + 1:
            break
        reach += coin
    return reach + 1
```

**不变量归纳证明**：

初始时，`reach = 0`，命题"我们能表示`[0, 0]`中所有整数"显然成立（空集和为0）。

归纳步：假设处理前i个硬币后，`[0, reach]`中所有整数均可达（通过子集和）。取第i+1个硬币`coin`：
- 若`coin ≤ reach + 1`：对于`[0, reach + coin]`中任意整数t，若`t ≤ reach`，由归纳假设可达；若`reach < t ≤ reach + coin`，则`t - coin ∈ [0, reach]`，由归纳假设`t - coin`可达，故`t`也可达（选取`t - coin`的子集再加上`coin`）。更新`reach += coin`，归纳假设对i+1成立。
- 若`coin > reach + 1`：则`reach + 1`无法被任何子集和表示（因为最小的新硬币已超过缺口），断裂。

算法时间复杂度O(n log n)（排序主导），空间O(1)。

### 2.3 LeetCode 128：加法连续性的断裂检测

> **题目**：在乱序数组中，找最长的连续整数序列的长度（如{100,4,200,1,3,2}中，{1,2,3,4}长度为4）。

128的精妙在于**起点剪枝**：对于序列`a, a+1, a+2, ...`，只从序列的"起点"（即`a-1`不在集合中的元素a）开始向右延伸。这保证每个元素至多被访问两次，总时间O(n)。

```python
def longestConsecutive(nums: list[int]) -> int:
    s = set(nums)
    best = 0
    for x in s:
        if x - 1 not in s:   # x是某段连续序列的起点
            cur = x
            length = 1
            while cur + 1 in s:
                cur += 1
                length += 1
            best = max(best, length)
    return best
```

128与1798的区别在于：1798检测从0开始的前缀是否连续，128检测任意位置的连续片段。但两者的核心工具是相同的：**连续性条件的判断**（相邻元素差是否为1）。

### 2.4 三题统一：Reachability Continuity Detection框架

将2568、1798、128放在一起，可以提炼出**Reachability Continuity Detection（RCD）框架**：

| 题目 | 空间 | 步进单位 | 任务 | 断裂行为 |
|------|------|---------|------|---------|
| 2568 | OR空间 | ×2（检查2的幂次） | 找第一个缺失原子 | 返回缺失的幂次 |
| 1798 | 加法空间 | +coin（排序后） | 找最大连续前缀 | 返回reach+1 |
| 128 | 加法空间 | +1（标准步进） | 找最长连续片段 | 更新最大长度 |

三题在RCD框架下是**异父兄弟**：128在加法空间用+1步进检测连续性断裂，2568在OR空间用×2步进检测原子缺失，1798在加法空间用动态步进检测前缀覆盖断裂。

这里有一个值得注意的代数差异：加法空间的步进 +1 是均匀的，而OR空间的步进 ×2 是指数的。这一差异根植于两个代数结构的根本不同——前者是可消幺半群，后者是幂等半格——但在"2的幂次"这一特殊生成基下，两个结构的前缀可达集恰好重合。

## 第三章：从检测到修补 — 连续性的主动构造

前两章都在讨论**检测**：给定一个集合，判断其连续性状态。第三章提出一个新问题：如果连续性断裂了，能不能**主动修补**？

### 3.1 LeetCode 41：MEX的极致空间压缩

> **题目**：在O(n)时间、O(1)空间内，找到整数数组中第一个缺失的正整数。

41题的关键洞察：**答案必然在`[1, n+1]`范围内**，其中n是数组长度。这将无界搜索空间压缩到有限范围。

然后，利用**原地哈希**——将数组下标`i`用来"标记"整数`i+1`是否存在：

```python
def firstMissingPositive(nums: list[int]) -> int:
    n = len(nums)
    # 将每个在[1,n]范围内的数放到对应位置
    for i in range(n):
        while 1 <= nums[i] <= n and nums[nums[i]-1] != nums[i]:
            nums[nums[i]-1], nums[i] = nums[i], nums[nums[i]-1]
    # 找第一个不匹配的位置
    for i in range(n):
        if nums[i] != i + 1:
            return i + 1
    return n + 1
```

41题是RCD框架中的极端情况：它不仅要检测连续性断裂，还要在O(1)额外空间内完成——通过将数组本身用作哈希表，实现了空间的"原地折叠"。

**与2568的对比**：2568的答案空间是`{1,2,4,8,...}`（指数稀疏），41的答案空间是`{1,2,3,...,n+1}`（线性稠密）。2568用哈希集合检测稀疏原子，41用原地哈希检测稠密整数——同样的RCD思想，不同的空间适配。

### 3.2 LeetCode 330：连续性的主动扩张

> **题目**：给定一个排序数组和目标n，最少需要添加多少个数，使得`[1, n]`中所有整数都能被子集和表示？

这里，`reach`不变量从"检测断裂"演变为"驱动修补"。每次断裂时，我们添加一个新数来填补缺口并最大化`reach`的扩张：

**命题2（LC330最优性定理）**：当`reach`已覆盖`[0, reach]`，且下一个可用元素`nums[i] > reach + 1`时，最优的补丁是`reach + 1`，使`reach`更新为`2*reach + 1`。

**证明（交换论证，Exchange Argument）**：

设我们选择添加一个值`p`（`1 ≤ p ≤ reach + 1`，因为任何`p > reach + 1`都无法填补`reach + 1`这个缺口）。添加后，`reach`更新为`reach + p`。

在`1 ≤ p ≤ reach + 1`的所有选择中，`p = reach + 1`使得更新后的`reach`最大（`= 2*reach + 1`）。

设有任意其他方案选择`p' < reach + 1`，则更新后`reach' = reach + p' < reach + (reach+1) = 2*reach+1`。经过同样步骤后，该方案覆盖的范围严格不优于选择`reach+1`的方案。由交换论证，贪心选择`reach+1`全局最优。 ∎

```python
def minPatches(nums: list[int], n: int) -> int:
    patches = 0
    reach = 0
    i = 0
    while reach < n:
        if i < len(nums) and nums[i] <= reach + 1:
            reach += nums[i]
            i += 1
        else:
            reach += reach + 1  # 补丁reach+1，reach翻倍加一
            patches += 1
    return patches
```

**复杂度**：O(m + log n)，其中m为数组长度。每次补丁使reach至少翻倍，故补丁次数至多O(log n)次。

## 第四章：OR的对偶世界 — 单向传染与逆向构造

### 4.1 OR单向传染的形式化

在第一章中，我们从"原子不可分解性"角度理解了OR单向传染性。这里给出更形式化的刻画。

定义OR运算下的**bit偏序**：`a ≤_OR b` 当且仅当 `(a | b) = b`，即a的所有1-bit都是b的1-bit的子集。在这一偏序下，`(Z≥0, |)` 构成一个**布尔半格（Boolean semilattice）**：

- OR是格的**上确界**（join）运算；
- AND是格的**下确界**（meet）运算；
- OR运算的单调性即是在这个偏序下的"只升不降"。

**OR可达集的结构定理**：给定集合S，S的所有子集的OR值构成的集合`R(S)`，在bit偏序意义下是S的**向上闭包（upset）**的格。换言之，R(S)中的元素恰好是S中元素的所有bit并集。

这一结构定理揭示了OR传染的本质：一个bit一旦在某个元素中出现，它就永久地"污染"了整个可达集——它会出现在所有包含该元素的子集的OR结果中。

### 4.2 LeetCode 3133：bit交织的逆向构造

> **题目**：给定整数x和n，构造一个长度为n的严格递增正整数数组，使得数组中所有元素的AND等于x，并最小化数组的最后一个元素。

这道题是2568的**对偶**：
- **2568**：在AND无约束下，找OR不可达的最小正整数（探测OR空间的"洞"）；
- **3133**：在AND有约束（必须保留x的所有1-bit）下，构造最小的可达终点（填充AND约束下的OR空间）。

AND约束的含义：数组中每个元素都必须包含x的所有1-bit（因为任何元素缺少某个bit，AND就会清零该bit）。x的0-bit则是**自由位**——数组元素可以在这些位置自由取0或1。

**bit交织算法**：将n-1的二进制表示，逐位嵌入x的0-bit（自由位）中。

```python
def minEnd(n: int, x: int) -> int:
    result = x
    n -= 1  # 我们需要插入n-1个额外的增量
    bit_pos = 0
    while n > 0:
        # 找x的下一个0-bit位置
        while (x >> bit_pos) & 1:
            bit_pos += 1
        # 将n-1的对应bit嵌入该位置
        if n & 1:
            result |= (1 << bit_pos)
        n >>= 1
        bit_pos += 1
    return result
```

**为什么这是最优的？** 因为x的1-bit必须保持（AND约束），而x的0-bit是我们唯一能利用的"增量空间"。将n-1嵌入这些自由位，等价于在自由位构成的子空间里数到n-1——这在自由位空间中是最小的第n个元素，经过bit交织后在原空间中也是最小的合法第n个元素。

### 4.3 2568与3133的对偶图景

| 维度 | 2568 | 3133 |
|------|------|------|
| 约束 | 无AND约束 | x的1-bit必须保留 |
| 目标 | 找最小OR不可达点 | 找最小合法可达终点 |
| 方向 | 探测缺口 | 构造覆盖 |
| 操作 | 检查2的幂次是否在集合中 | 将n-1嵌入自由位 |
| 数学结构 | OR空间的"洞"探测 | AND约束下的OR空间构造 |
| 复杂度 | O(n + log M) | O(log(n) × log(x)) |

两题共同构成了对OR宇宙"边界"与"填充"的完整描述。2568问"哪里有洞"，3133问"如何在约束下最小地填满"。它们是同一代数结构的两张面孔。

## 第五章：统一场论 — 有序幺半群上的降维打击

### 5.1 元定理的形式化陈述

前四章从具体题目出发，现在将其提炼为统一的数学框架。

**元定理（Monotone Reachability Meta-Theorem）**：

设`(M, ⊕, 0, ≤)`为一个有序幺半群（ordered monoid），其中`⊕`是单调的（`a ≤ b ⟹ a ⊕ c ≤ b ⊕ c`）。设S为M中的有限集合，排序为`s_1 ≤ s_2 ≤ ... ≤ s_m`。定义**前缀可达集扩展不变量**`reach`为：

> 当前已确认可以表示为S的子集在`⊕`下的合成值，且这些值构成`[0_M, reach]`的连续前缀。

则：

1. **连续性判据**：`reach`的更新规则为：若`s_i ≤_M reach ⊕ unit`（`unit`为自然步进），则`reach ← reach ⊕ s_i`；否则断裂。
2. **降维定理**：判断前缀可达集的最大范围，时间复杂度由`O(2^m)`（暴力枚举子集）降至`O(m log m)`（排序+线性扫描）。
3. **最优修补引理**：断裂时，最优修补值为`reach ⊕ unit`，使`reach`扩张最大化。

这个元定理的"降维打击"之所以成立，根本原因是**有序幺半群的单调性**：我们不需要检查所有子集，只需要按序处理每个元素，因为小元素的贡献无法被大元素替代。

### 5.3 OR空间与加法空间的代数桥梁

这是本报告中最重要的理论区分。

**两个代数结构的根本差异**：

| 性质 | 加法空间 `(Z≥0, +)` | OR空间 `(Z≥0, \|)` |
|------|-------------------|-------------------|
| 代数类型 | 可消幺半群 | 幂等半格 |
| 可消性 | `a+c=b+c ⟹ a=b` | `a\|c=b\|c` 不能推 `a=b` |
| 幂等性 | `a+a=2a≠a`（一般） | `a\|a=a`（永远） |
| 逆元 | 有（负数扩展） | 无（无法"取消"一个bit） |
| 完备性 | Brown准则四条件全满足 | 因幂等性不满足可分解性 |

**反例**：设S={3, 5}。
- OR可达集：{0, 3, 5, 3|5} = {0, 3, 5, 7}
- 加法可达集（子集和）：{0, 3, 5, 3+5} = {0, 3, 5, 8}

{7}在OR可达但加法不可达；{8}在加法可达但OR不可达。**两个空间的可达集严格不相等。**

**计算复杂度的鸿沟**：
- OR可达集的计算：O(n × bitwidth)，多项式时间；
- 加法可达集（子集和问题）：NP-Hard。

**等价的唯一条件**：当且仅当S中每个元素都是2的幂次（即各元素的bit位两两不重叠），两个可达集完全相同。这正是2568算法正确性的代数根基：**在2的幂次集合上，OR-closure = Σ-closure**。

**统一的桥梁**：尽管二者不同构，它们都满足"有序幺半群上的单调覆盖扩展引理"：

> 设`(M,⊕)`满足单调性。若当前已覆盖`[0, reach]`，且新元素`s ≤ reach + 1`（适当定义"≤"和"+1"），则更新后可覆盖`[0, reach ⊕ s]`。

这一引理是两个空间所有相关算法的共同数学脊梁——不是"完全等价"，而是"**形式类比下的深层共构**"。

### 5.4 降维打击的哲学意义

为什么"运算单调性 + 连续性不变量"能将指数复杂度压缩到多项式？

本质答案是：**有序结构消灭了不确定性**。

在一个无序的集合上，知道前i个元素无法预测第i+1个元素的影响，因此必须穷举。而在有序幺半群上，单调性保证了"小的先来"是最优策略——前i个较小的元素决定了`reach`的当前值，而`reach`完全决定了第i+1个元素是否有用（`s_i ≤ reach+1`即有用）。

这是一种**递推结构消灭组合爆炸**的范式。类似的思想出现在：
- **动态规划**（状态转移方程压缩了历史信息）；
- **贪心算法**（局部最优等价全局最优，需要单调性或交换性保证）；
- **拟阵理论**（独立集的遗传性使贪心算法在拟阵上总是正确的）。

7道题的共同点，正是在各自的运算空间中找到了这个"递推结构"，从而完成了降维。

## 第六章：数学基础深探

### 6.1 Brown准则与Complete Sequences

**Brown准则**：正整数序列`a_1 ≤ a_2 ≤ ...`是"完备序列"（Complete Sequence，即其所有子集和可表示所有从1到某值的正整数）的充要条件是：

```
∀k ≥ 1: a_k ≤ 1 + Σ_{i<k} a_i
```

这正是reach不变量在加法空间的形式化。当Brown准则在第k步失败时，`a_k > reach + 1`，连续性断裂。

Brown准则揭示了加法空间中"完备性"的极深数学结构，与数论中的Fibonacci序列、以及OEIS中完备序列的研究密切相关。值得注意的是，Brown准则的四个条件（交换律、结合律、单调性、可分解性）在加法空间完全满足，但OR空间因幂等性不满足"可分解性"（`a|b=c`不能推`b`的唯一性），故Brown准则不能直接移植到OR空间，而必须用命题1（OR唯一生成引理）替代。

### 6.2 GF(2)线性代数与XOR基

XOR运算（`⊕`）与OR运算（`|`）在数学结构上有本质差异，但都属于"位运算家族"，且在算法竞赛中经常联合出现。

在GF(2)（二元域）上，每个整数可以视为GF(2)^n上的向量，XOR是向量加法，AND是分量乘法。

**XOR基（线性基）**：一组整数的XOR线性基是最小的生成集，使得原集合的所有子集的XOR值都能由基的子集XOR得到。XOR基的大小至多为整数的bit宽度（通常≤60）。

与OR的"原子"（2的幂次）类比：XOR基中的"原子"是不能由其他基向量XOR合成的向量。但XOR的代数结构是**域上的向量空间**（GF(2)^n），而OR的代数结构是**布尔半格**，两者各有各的降维工具：

| | OR空间 | XOR空间 |
|--|--------|---------|
| 代数结构 | 布尔半格 | GF(2)向量空间 |
| "原子" | 2的幂次（固定） | 线性基向量（动态） |
| 基的大小 | O(log M)（固定） | ≤ bitwidth（数据相关） |
| 降维方式 | 原子检查 | 高斯消元 |
| 典型题目 | LC 2568 | 最大异或子数组 |

### 6.3 Sprague-Grundy理论与MEX

MEX（Minimum Excludant，最小不属于集合的非负整数）是博弈论中**Sprague-Grundy理论**的核心工具。

Sprague-Grundy定理：任何无偏博弈（Impartial game）的状态都可以用一个Grundy值（或nimber）描述，Grundy值等于该状态所有后继状态的Grundy值集合的MEX。

LeetCode 41直接计算MEX（最小缺失正整数），与Sprague-Grundy理论形成语义上的桥梁。在更深的层面上，"寻找第一个缺失元素"这一操作在博弈分析、并查集路径压缩、以及数据流的完备性检测中反复出现，体现了MEX作为"离散连续性测度"的普遍性。

### 6.4 拟阵理论与贪心正确性

**拟阵（Matroid）**：集合E上的拟阵是一族子集族I，满足：
1. **遗传性**：若A∈I，B⊆A，则B∈I；
2. **扩张性**：若A,B∈I，|A|<|B|，则∃x∈B\A使得A∪{x}∈I。

**贪心算法在拟阵上总是正确的**（Rado-Edmonds定理）：对任意权重函数，按权重从大到小贪心选取独立集中的元素，得到的最大权独立集是最优的。

330题的贪心（选取`reach+1`作为补丁）可以在拟阵框架下理解：可行补丁集合构成拟阵的独立集，贪心策略选取"最大扩张"的补丁，等价于在这一拟阵上的最大权独立集算法。交换论证（Exchange Argument）是拟阵扩张性的算法证明形式。

拟阵理论为算法的贪心正确性提供了最深刻的数学保证，它揭示了**为什么某些贪心策略是正确的**（问题具有拟阵结构），而另一些却不是（问题不具备拟阵结构，如0-1背包）。

## 结语：算法的尽头是数学

从LeetCode 2568出发，我们走过了一段不寻常的旅程。

这道"简单"题目的答案只有三行代码，却蕴含着一个完整的数学宇宙：2的幂次是这个宇宙的基本粒子，OR单向传染性是这个宇宙的物理定律，reach不变量是量度连续性的"宇宙温度"，而元定理则是这个宇宙的"统一场方程"。

七道题之间的关系，不是"套路相似"，而是**数学同构**（在各自的代数空间内）。2568与338是互补的原子论视角。1798和128是加法宇宙中同一不变量的两种读取方式。41是极限空间压缩下的MEX变体。330是不变量从"被动读"到"主动写"的范式转换。3133是OR宇宙的对偶边界，与2568共同刻画了可达集的"内"与"外"。

更深刻的是：OR空间与加法空间**看似相似、实则不同构**，但它们都满足"有序幺半群上的单调覆盖扩展引理"。这个引理不是对两个空间"强行统一"，而是在更抽象的层面发现了它们共同遵循的**代数规律**。正是这个规律，使得所有7道题都能在O(n log M)以内求解——指数级的组合复杂度被单调性融化，降维打击由此完成。

**算法的尽头是数学。而数学的乐趣，在于发现看似无关的事物背后，深藏着同一条脉络。**
