# 数学算法知识体系：从公式到可复用模板

> 数学题并不是“记住一个公式就结束”。真正稳定的能力是：识别离散结构，明确公式成立的前提，把数学推导翻译成不会溢出、不会算错边界的程序。

---

## 一、缘起：算法为什么最终会遇到数学

数据结构负责组织状态，算法负责改变状态，数学负责压缩状态。

一个长度为 `n` 的过程若按题意模拟，可能需要 `O(n)`、`O(n^2)` 甚至指数时间；一旦发现周期、同余、组合恒等式或线性递推，问题可能被压缩为
`O(log n)` 或一个公式。数学算法的核心价值不是“计算”，而是消除不必要的搜索。

常见的压缩方式：

| 原始问题         | 数学结构             | 压缩结果                       |
|------------------|----------------------|--------------------------------|
| 重复乘 `n` 次    | 指数的二进制分解     | 快速幂 `O(log n)`              |
| 枚举所有子数组   | 每个位置被包含的次数 | 贡献法 `O(n)`                  |
| 模拟巨大递推     | 线性变换复合         | 矩阵快速幂 `O(k^3 log n)`      |
| 枚举所有排列     | 阶乘进制             | 康托展开 `O(n log n)`          |
| 逐个判断质数     | 合数拥有最小质因子   | 筛法 `O(n log log n)` / `O(n)` |
| 二维覆盖逐格统计 | x 事件 + y 覆盖长度  | 扫描线                         |

数学算法需要同时守住三层正确性：

1. **模型正确**：问题是否真的满足公式前提。
2. **推导正确**：等价变形、计数口径和边界是否一致。
3. **实现正确**：类型范围、模数性质、浮点误差和负数语义是否安全。

## 三、工业级实现：公式如何安全落地

### 3.1 整数范围是第一条前置条件

Java 整数范围：

| 类型         |                      范围 | 典型用途             |
|--------------|--------------------------:|----------------------|
| `int`        |         `[-2^31, 2^31-1]` | 下标、计数、较小坐标 |
| `long`       |         `[-2^63, 2^63-1]` | 乘积、答案、模运算   |
| `BigInteger` |                受内存限制 | 精确大整数           |
| `double`     | 约 15~16 位十进制有效数字 | 概率、距离、连续量   |

危险表达式：

```java
long product = a * b;       // 乘完以后才赋给 long，若 a/b 是 int，可能已在 int 中溢出
long square = x * x;        // x 是 long 也可能溢出
int mid = (left + right) / 2;
```

更稳妥的写法：

```java
long product = (long) a * b;
long safe = Math.multiplyExact(a, b);
int mid = left + (right - left) / 2;
```

`MathUtil.safeMul` 使用倍增法计算 `(a*b) mod m`，不会先产生可能溢出的完整乘积。代价是从 `O(1)` 变成 `O(log b)`，因此只有模数接近
`long` 上界时才有必要使用；模数为 `1_000_000_007` 且乘数已取模时，普通 `long` 乘法足够。

### 3.2 模运算不是普通整数运算

同余定义：

```text
a ≡ b (mod m)  ⇔  m | (a-b)
```

封闭性：

```text
(a+b) mod m = ((a mod m)+(b mod m)) mod m
(a-b) mod m = ((a mod m)-(b mod m)+m) mod m
(a*b) mod m = ((a mod m)*(b mod m)) mod m
```

除法没有对应的直接规则：

```text
a / b mod m  ≠  (a mod m) / (b mod m)
```

只有当 `gcd(b,m)=1` 时，`b` 才存在模逆元：

```text
a / b mod m = a * inv(b) mod m
```

若 `m` 为质数且 `b` 不被 `m` 整除，可由费马小定理得到：

```text
inv(b) = b^(m-2) mod m
```

否则使用扩展欧几里得。调用 `MathUtil.modInverse` 前必须确认模数是质数；通用场景使用 `modInverseGeneral`。

### 3.3 GCD、贝祖定理和线性同余

欧几里得算法：

```text
gcd(a,b) = gcd(b,a mod b)
```

原因是 `a=qb+r`，`a` 与 `b` 的公因子集合和 `b` 与 `r` 的公因子集合相同。

扩展欧几里得不仅求 `gcd`，还求系数：

```text
ax + by = gcd(a,b)
```

由此得到两个重要结论：

1. `ax+by=c` 有整数解，当且仅当 `gcd(a,b) | c`。
2. `a` 在模 `m` 下有逆元，当且仅当 `gcd(a,m)=1`。

线性同余：

```text
ax ≡ b (mod m)
```

等价于：

```text
ax + my = b
```

因此有解条件是 `gcd(a,m) | b`。`NumberTheory.solveLinearCongruence` 返回最小非负解及解的周期。

### 3.4 质数算法怎么选

| 需求                                | 模板         | 复杂度                    |
|-------------------------------------|--------------|---------------------------|
| 判断一个较小 `n` 是否为质数         | 试除到 `n/i` | `O(sqrt(n))`              |
| 分解一个整数                        | 试除         | `O(sqrt(n))`              |
| 求 `[1,n]` 全部质数                 | 埃氏筛       | `O(n log log n)`          |
| 同时求质数/最小质因子               | 线性筛       | `O(n)`                    |
| 求巨大区间 `[L,R]` 内质数，区间不宽 | 分段筛       | 约 `O((R-L+1) log log R)` |

边界提醒：

- `0`、`1` 不是质数。
- 循环条件写 `i <= n / i` 可避免 `i*i` 溢出。
- 分段筛起点是 `max(p*p, ceil(L/p)*p)`，否则会误筛掉 `p` 本身。
- `R-L+1` 必须能放进数组下标类型。

### 3.5 组合数：精确值与模值是两套问题

定义：

```text
C(n,k) = n! / (k!(n-k)!)
P(n,k) = n! / (n-k)!
```

单次精确计算优先使用乘除交替：

```text
C(n,k) = Π(i=1..k) (n-i+1)/i
```

但即使最终结果能放入 `long`，中间乘法也可能先溢出。`CombinatoricsUtil.binomialExact` 使用 `BigInteger` 保证精确。

同一质数模数下大量查询：

```text
C(n,k) = fact[n] * invFact[k] * invFact[n-k] mod p
```

预处理 `O(n)`，单次 `O(1)`。前提：

- `p` 是质数。
- 当前模板要求 `n < p`。
- 若 `n >= p`，需要 Lucas 定理或其他分解方法，不能继续套阶乘逆元。

### 3.6 三个重要组合数列

#### 卡塔兰数

```text
Cn = C(2n,n)/(n+1)
Cn = Σ(i=0..n-1) Ci*C(n-1-i)
```

识别信号：

- `n` 对合法括号
- `n` 个节点的不同 BST
- 凸多边形三角剖分
- 不越过对角线的单调路径

#### 第二类 Stirling 数

把 `n` 个不同元素分成 `k` 个非空、无标号集合：

```text
S(n,k) = S(n-1,k-1) + k*S(n-1,k)
```

第 `n` 个元素要么单独成组，要么进入已有 `k` 组之一。

#### 错排

`n` 个元素全部不在原位置：

```text
D(0)=1, D(1)=0
D(n)=(n-1)(D(n-1)+D(n-2))
```

### 3.7 贡献法：把枚举对象改成枚举元素

长度为 `n` 的数组中，下标 `i` 被多少个子数组包含？

- 左端点可选 `0..i`，共 `i+1` 种。
- 右端点可选 `i..n-1`，共 `n-i` 种。

所以贡献次数：

```text
(i+1)(n-i)
```

若要求 `nums[i]` 是区间中某个值的唯一代表，设相同元素前一次出现于 `prev[i]`，后一次出现于 `next[i]`：

```text
(i-prev[i]) * (next[i]-i)
```

贡献法的关键问题不是公式，而是“一个答案应由哪个元素唯一负责”。责任边界一旦不唯一，就会重复计数。

### 3.8 概率 DP 与期望 DP

概率 DP 通常向后分配：

```text
dp[next] += dp[current] * transitionProbability
```

期望 DP 通常从当前状态列方程：

```text
E[current] = immediateCost + Σ p(current→next) * E[next]
```

若有概率 `p` 留在原状态：

```text
E = 1 + pE + (1-p)E'
E = (1 + (1-p)E') / (1-p)
```

自环项必须移到左边。直接把它当普通后继会产生循环依赖或错误答案。

期望线性性：

```text
E[X1+X2+...+Xn] = E[X1]+E[X2]+...+E[Xn]
```

它不要求变量独立。许多看似复杂的联合随机过程，可以拆成若干“事件是否发生”的指示变量。

### 3.9 计算几何为什么优先用叉积

向量 `a=(x1,y1)`、`b=(x2,y2)`：

```text
dot(a,b)   = x1*x2 + y1*y2
cross(a,b) = x1*y2 - y1*x2
```

点积回答：

- 夹角是锐角、直角还是钝角
- 一个向量在另一个方向上的投影

叉积回答：

- 两向量旋转方向
- 三点是否共线
- 平行四边形有向面积

三点 `A→B→C`：

- `cross(A,B,C)>0`：逆时针
- `cross(A,B,C)<0`：顺时针
- `cross(A,B,C)=0`：共线

斜率需要除法，会遇到竖直线和浮点误差；叉积只需要乘减，所以整数坐标判定优先使用叉积。

### 3.10 线段相交的完整判定

一般相交需要两组跨立：

```text
C、D 位于直线 AB 两侧
A、B 位于直线 CD 两侧
```

但还要补上：

- 端点落在另一条线段上
- 两线段共线且部分重叠
- 退化线段（两个端点相同）

`ComputationalGeometry.segmentsIntersect` 将端点接触也视为相交。若题目要求“严格内部相交”，需要排除端点和共线情况。

### 3.11 多边形面积与方向

鞋带公式的二倍有向面积：

```text
area2 = Σ(xi*y(i+1) - yi*x(i+1))
```

- `area2>0`：通常为逆时针
- `area2<0`：通常为顺时针
- 实际面积为 `abs(area2)/2`

整数坐标下先保留 `area2`，可以精确表达 `.0` 或 `.5` 面积。

### 3.12 高精度的分层设计

手写高精度不要让符号、小数点和逐位运算纠缠在一个循环中。

建议分层：

1. 解析并移除符号。
2. 对齐小数位，转成等效整数。
3. 调用非负整数加减乘除核心。
4. 放回小数点。
5. 去除前导零、末尾零和多余小数点。
6. 恢复符号，规范零为 `"0"`。

工程项目中：

- 精确整数使用 `java.math.BigInteger`。
- 精确十进制使用 `java.math.BigDecimal`，并明确 `scale` 和 `RoundingMode`。
- 金额禁止用 `double`。

## 四、本质权衡：模板不是越高级越好

### 4.1 预处理还是单次计算

| 场景                     | 选择                  |
|--------------------------|-----------------------|
| 单次质数判断             | `O(sqrt(n))` 试除     |
| 十万次质数判断且上界固定 | 筛法                  |
| 单次组合数               | 乘除式 / `BigInteger` |
| 大量模组合数查询         | 阶乘与逆阶乘          |
| 单次递推且 `n` 小        | 线性 DP               |
| 递推阶数固定、`n` 极大   | 矩阵快速幂            |

预处理本质是用空间和初始化成本交换查询速度。不要为了一个查询建立百万级数组。

### 4.2 精确整数还是浮点数

优先精确整数的场景：

- 共线、方向、相交等离散判定
- 计数
- 模运算
- 金额

适合浮点数的场景：

- 欧氏距离
- 三角函数
- 概率和期望
- 题目允许误差的连续优化

混合策略：能用整数完成判定就先用整数，只在最终输出时转为 `double`。

### 4.3 公式还是动态规划

公式通常更快，但前提更强；DP 更通用，但状态和复杂度更高。

例如卡塔兰数：

- 求单个精确值：组合公式。
- 求 `C0..Cn` 全部值：递推。
- 带额外限制：通常回到 DP。

先寻找标准模型，再确认限制是否破坏模型。名字相似不代表还能直接套公式。

### 4.4 试除、筛法还是更高级素性测试

当前包覆盖基础储备：

- `O(sqrt(n))` 试除
- 埃氏筛
- 线性筛
- 分段筛

当 `n` 接近 `long` 上界并需要快速素性判断/分解时，应继续学习：

- Miller-Rabin 素性测试
- Pollard Rho 质因数分解

这两者属于进阶模板，不应与基础筛法混成一个入口。

## 六、融会贯通：数学与其他算法的连接

### 6.1 数学与二分答案

二分不是只能查数组。只要判定函数具有单调性，就能二分答案。

典型连接：

- 阶乘尾零数量随 `n` 单调增加。
- 圆半径越大，能覆盖的点不会减少。
- 给定面积阈值的扫描线判定。

数学负责证明单调性，二分负责定位边界。

### 6.2 数学与前缀和

前缀和本质是群上的累积：

```text
range(l,r) = prefix(r) - prefix(l-1)
```

进一步：

- 前缀和相等 → 中间区间和为零。
- 前缀余数相等 → 中间区间和被 `k` 整除。
- 前缀异或相等 → 中间区间异或为零。
- 二维前缀和 → 矩形容斥。

### 6.3 数学与动态规划

很多组合恒等式就是 DP 转移：

- 杨辉三角：从左上和正上方转移。
- Stirling 数：新元素单独成组或加入旧组。
- 卡塔兰数：枚举左右子结构规模。
- 期望 DP：对下一状态做概率加权。

公式是被消去状态后的 DP，DP 是尚未化简的公式。

### 6.4 数学与图论

- 矩阵快速幂可以统计固定长度路径数。
- `gcd` 可刻画状态跳转能到达的同余类。
- 概率转移矩阵对应马尔可夫链。
- 几何图中的边由距离、相交或可见性决定。

### 6.5 数学与贪心

贪心的正确性经常依赖数学证明：

- 排序不等式
- 交换论证
- 单调性
- 局部增量比较
- 次模性 / 拟阵结构

“看起来应该选最大”不是证明。需要说明交换后为何不变差。

## 十、模板使用原则

1. **先写前提，再写公式。** 例如“模数为质数”是逆元模板的一部分，不是注释装饰。
2. **先估范围，再选类型。** 复杂度正确但数值溢出仍是错误算法。
3. **先保证唯一计数，再优化。** 贡献法和容斥最怕口径不清。
4. **先用精确判定，再用浮点输出。** 尤其是计算几何。
5. **先选择最小够用模板。** 单次查询不做重预处理，基础规模不引入高级数论。
6. **把反例当作模板的一部分。** `0/1`、负数、重复点、共线、空集合、模数非质数都应主动检查。

数学模板的最终标准不是“背得出来”，而是能说明：

- 它从哪里推导而来；
- 它依赖哪些前提；
- 它为什么比直接模拟更快；
- 它在哪些边界会失效；
- 它与其他算法结构如何组合。
