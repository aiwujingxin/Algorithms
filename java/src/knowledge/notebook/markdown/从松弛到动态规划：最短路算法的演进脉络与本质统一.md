# 从松弛到动态规划：最短路算法的演进脉络与本质统一

**这篇综述想讲清一件事**：最短路的一整个算法家族（Dijkstra、Bellman\-Ford、SPFA、分层图 DP……）看似招式各异，其实都长在同一块地基上——**一个原子动作「松弛」**。我们会沿着「**基础概念 → 算法演进 → 与动态规划的本质联系**」三步往上走：先砌好松弛与状态两块砖，再看同一个松弛怎样演化出四种调度策略，最后揭示「Dijkstra 其实是 DP 的一个特例」这一贯通性结论。

**阅读对象**：已了解 DP、最短路、Dijkstra、递归基本概念，想把零散模板升级成一套「知其所以然」体系的读者。

---

# 第一部分 · 地基：松弛与状态两块原子砖

整套理论只由两块最小的「砖」砌成：一块叫**状态**（描述「我现在处在什么局面」），一块叫**松弛**（描述「我怎么让这个局面变得更好」）。后面所有算法，都只是这两块砖的排列组合。

## 1\.1 砖一：状态 = 充分统计量

**定义**：一个**状态**，是「为了推算未来，你必须记住的最小信息集合」。数学上叫**充分统计量（sufficient statistic）**——记住了它，过去**怎么走到这里**就不再重要。

看最经典的斐波那契 $f(n)=f(n-1)+f(n-2)$：要算 $f(n)$，你只需记住前两项，**不需要**知道它们又是怎么算出来的。「前两项」就是这里的充分统计量，也就是状态。

状态选得对不对，判据只有一句：**记住它，未来就与过去无关**。这块砖还决定了问题有几个维度——**状态里有几个坐标，解空间就有几维**（斐波那契一维，背包两维，带约束最短路两维，以此类推）。这一点会在第三部分「升维」时反复用到。

## 1\.2 砖二：松弛（relaxation）= 唯一的原子动作

**定义**：松弛一条边 $u \to v$，就是**试着借道 u，把「到 v 的当前最优记录」改得更好**。

```text
if dist[u] + w(u, v) < dist[v]:
    dist[v] = dist[u] + w(u, v)   # 改小才更新，记一笔更优的走法
    prev[v] = u                    # (要还原路径时)

```

为什么叫「松弛」？名字来自 **relaxation = 松开一个过紧的约束**。全程 $dist[v]$ 始终是**真实最优值的一个高估上界**：初始往死里高估（$+\infty$），每成功松弛一次就往下掉一点、离真值更近一点，**只减不增、单调逼近**。

**几何画面**：把 $dist[v]$ 想成一根绷太紧的橡皮筋（估值虚高）。发现更优走法，就把它**放松**一点，缩到更真实的长度——所以是「松\-弛」。记住这根「越勒越短的橡皮筋」，它是后面「单调收敛」「不动点」的直觉源头。

### 收敛判据：三角不等式

松弛松开的到底是哪条约束？是**三角不等式**——任何最短路解都必须满足它：

$dist[v] \le dist[u] + w(u,v)$

当某条边**违反**了它（$dist[u]+w \lt dist[v]$，说明 v 的估值虚高），就松弛这条边把不等式扳回成立。于是有了全篇统一的终止判据：

**统一终止判据**：当图里**所有边都无法再被松弛**（全部满足三角不等式）时，$dist[\ ]$ 就是最优解，算法收敛。**最短路与 DP 都在等这一刻。**

## 1\.3 三面承重墙 \+ 一面隐性墙

光有两块砖还不能盖楼，得先确认地基**能承重**。一个问题能不能用 DP / 最短路解，取决于三面墙同时立住：

|承重墙|是什么|立不住会怎样|
|---|---|---|
|**无后效性**|状态一旦确定，后续只依赖它本身，与「怎么到这儿的」无关 ⟹ 依赖关系构成 **DAG**（有向无环）|有环则互相依赖、无法定序，推不动|
|**最优子结构**|大问题的最优解，能由子问题的最优解**用 min/max 拼**出来|拼不出全局最优（如「最长不含重复字符子串」不满足朴素拼接）|
|**重复子问题**|同一个子问题被反复用到，值得记下来复用|不重复则记忆化无收益，退化成暴力搜索|

斐波那契是三面墙都立住的最小样本：$f(n)$ 只依赖 $f(n-1)/f(n-2)$（无后效）；大项由小项相加（最优子结构的加法版）；$f(n-2)$ 被反复用到（重复子问题）——所以朴素递归指数爆炸，加记忆化立刻变线性。

**墙与砖的对应**：**无后效性**是对「状态」这块砖的要求（选对维度，依赖才无环）；**最优子结构**是对「松弛」这块砖的要求（min/max 合并才合法）；**重复子问题**决定要不要给松弛结果**存档**（记忆化）。

还有一面**隐性的第四面墙——松弛的单调性**：它专门决定「能不能用 Dijkstra 秒定型」。它要求沿一条边松弛结果只会不减，即 $dist[v]=dist[u]+w \ge dist[u]$，也就是**边权非负**。这面墙立住，才有第二部分里最省力的贪心调度。

## 1\.4 关键承重梁：依赖 ≠ 处理顺序

这是全篇最容易塌、也最关键的一根梁。很多人学 Dijkstra 时最大的困惑是：「它按代价排序处理节点，那计算顺序岂不是乱的？怎么保证依赖不出错？」答案是——**代码里藏着两套完全独立的「顺序」，分开看，疑云立散。**

|两根正交的「顺序」|是什么|由谁决定|管什么|
|---|---|---|---|
|**依赖关系**|谁的值由谁推出|边的连法（DAG 结构）|**正确性**：被依赖方必须先定型|
|**处理顺序**|程序实际先算谁|调度策略（如按代价排序）|**效率**：可按任意合法拓扑序自由调度|

**这根梁的承重原理**：Dijkstra 按代价弹出的处理顺序，阶段号可能是 0→1→2→1→2 反复横跳，却照样不乱。因为程序把**「自由的处理顺序」和「死板的依赖关系」解耦**了——顺序随便跳，但每次拿一个节点去松弛别人时，那个节点一定已经是最优（松弛单调 \+ 首次弹出即最优），层层依赖始终被正确满足。**依赖不变，调度可换。**

这条「依赖 ≠ 处理顺序」的洞察，正是理解第二部分「四种调度策略」和第三部分「Dijkstra 是 DP 特例」的钥匙：它们的差别从来不在依赖（都在解同一个方程），只在调度顺序。

# 第二部分 · 算法演进：同一个松弛，四种调度

核心洞察一句话：**最短路和 DP 从来没有几种「算法」，只有一个动作（松弛）\+ 几种调度策略。**差别只在「按什么顺序、松弛哪些边」。所有解法都在解同一个**Bellman 最优性方程**：

$dist[v] = \min_{(u \to v)} \{\, dist[u] + w(u,v) \,\}$

**文字解读**：到 v 的最短距离，等于「枚举所有能一步到达 v 的前驱 u，取 $dist[u]$ 加上那条边的权，再选最小」。这就是「最后一跳」的思想——不管最优路径长什么样，它的最后一条边一定是某个 $u \to v$。下面四种调度，只是回答同一个问题的不同策略：**解这个方程时，怎样避免无效的松弛？**

## 2\.1 四种调度策略总览

|调度策略|松弛谁|顺序|要求非负边？|
|---|---|---|---|
|**逐层 DP / Bellman\-Ford**|所有边|无脑遍历，每轮把所有边全松弛一遍，共 V−1 轮|否（可负边、可判环）|
|**SPFA**（BF 队列优化）|只松弛「值刚变小的点」的出边|谁被改小谁进队，带动邻居|否|
|**Dijkstra**|弹出点的出边|优先队列**按 dist 递增**弹，每点松弛一次|**是**（靠它秒定型）|
|**DFS \+ 记忆化**|状态间转移边|递归到谁算谁，算过记下（懒惰按需）|不涉及（无环即可）|

下面按「从最朴素到最精巧」的演进顺序，依次拆解 Bellman\-Ford → SPFA → Dijkstra，看清它们两两之间到底改了什么。

## 2\.2 Bellman\-Ford：无脑全松弛，但每轮精确前进一格

Bellman\-Ford 是最朴素的策略：**每一轮把所有边都松弛一遍，共跑 V−1 轮**。它看似「像暴力」，实则每一轮都在数学上精确地前进一格。

### 轮数 round 的物理含义（钥匙）

**循环不变量**：第 round 轮跑完后，$dist[v]$ = 从源点到 v、**最多用 round 条边**的最小花费。

- round=1 → 只准走 1 条边；round=k\+1 → 最多 k\+1 条边（k 个中转）。

- **每一轮解锁「多走一条边」的权限**——这正是它能处理「恰好 / 最多 k 条边」这类带约束最短路的根本原因（详见第三部分）。

### 为什么不能一次收敛，也不是每轮猛降

- 信息必须**一跳一跳**往前爬：节点 3 的最优依赖节点 2，节点 2 依赖节点 1，一轮松弛只推进一条边。**决定轮数的是路径的边数（深度），不是图的规模。**

- $\min$ 保证值**单调不增**；但多给一条边未必更便宜（直飞最优时新值被挡掉），所以**这一轮可能纹丝不动**。不是「每轮小很多」，而是「单调不增、随时可能停止变化」。

### snapshot / clone 的灵魂：防「一轮内连跳两级」

这是 Bellman\-Ford 代码里最容易写错、也最能体现本质的一处：

- 不克隆、直接滚动更新会导致：同一轮里节点 1 刚更新，马上拿它更新节点 2 → **一轮内偷走两条边**，击穿「最多 round 条边」约束。

- $snapshot = dist.clone()$**冻结上一轮的世界**：本轮所有松弛只读 snapshot、只写 dist。这就**严格保证**本轮每条边都建立在「上一轮至多 round−1 条边」的基础上，加这一条恰好 round 条，一条不多。

### 正确性证明（归纳法，无遗漏）

**归纳假设**：round−1 轮后，$dist[v]$ = 至多 round−1 条边的最小花费（对所有 v）。**归纳推进**：第 round 轮对每条边 $(u \to v)$ 松弛：

$dist[v] \leftarrow \min\Big(dist[v],\ \min_{u}\{\,snapshot[u] + w(u,v)\,\}\Big)$

任何「到 v 且用 ≤ round 条边」的最优路径，其**最后一条边**必是某个 $u \to v$；去掉它后的前缀是「到 u 且 ≤ round−1 条边」的路径，由归纳假设，$snapshot[u]$ 已是该前缀最优值。**为什么不遗漏**：内层循环枚举了图里每一条边 = 枚举所有可能的「最后一跳」，v 的最优路径不管最后一跳从哪来，那条边一定被扫到、一定参与了 $\min$。

**一句话总结**：单调收窄的边预算（snapshot）\+ 穷举式的最后一跳（遍历所有边）= 「精确 k 条边内最优、且无遗漏」的全部证明。

## 2\.3 SPFA：聪明的 Bellman，不是退化的 Dijkstra

**先纠正一个常见误解**：SPFA（Shortest Path Faster Algorithm）是 **Bellman\-Ford 的加速版**，不是 Dijkstra 的变种。把它当 Dijkstra 用会误解其性质与复杂度边界。

### 抓住的核心性质：松弛的「传染性」

Bellman\-Ford 的浪费在于每轮盲目松弛所有边。但一条边 $u \to v$ 只有在 u 的 dist 刚变小时，拿它松弛 v 才可能有效。于是 SPFA 抓住一个性质：

**只有 dist 刚变小的节点，才有资格去更新它的邻居。**一个节点更新了才可能「传染」给下游；没被传染的节点做松弛毫无意义。机制：用一个队列只装「dist 刚变小、还没去更新邻居」的节点。

```java
Queue<Integer> queue;  boolean[] inQueue;
dist[src] = 0;  queue.offer(src);  inQueue[src] = true;
while (!queue.isEmpty()) {
    int u = queue.poll();  inQueue[u] = false;
    for (每条边 u->v, 权 w) {
        if (dist[u] + w < dist[v]) {       // 松弛成功
            dist[v] = dist[u] + w;
            if (!inQueue[v]) {             // v 刚变小 -> 需去传染邻居
                queue.offer(v);  inQueue[v] = true;
            }
        }
    }
}

```

**本质**：SPFA = Bellman\-Ford \+ 「只处理真正发生变化的节点」的队列驱动，把「盲目全扫」改成「事件驱动的按需扩散」。

### 与 Dijkstra：形似，神不同

|维度|Dijkstra|SPFA|
|---|---|---|
|容器|优先队列（堆）|普通队列（FIFO）|
|取出顺序|按 dist **最小优先**|先进先出，**不排序**|
|一个点处理几次|定稿后**只一次**|可能**反复入队多次**|
|正确性靠什么|贪心不变量（取出即定稿）|迭代收敛（反复修正）|

**一句话点破**：SPFA 长着 Dijkstra 的「队列扩散」外壳，内核却是 Bellman 的「反复迭代收敛」。它主动**放弃** Dijkstra 的「取出即定稿」，换来**处理负权**的能力。

### 软肋与不可替代性

- **软肋**：最坏退化回 $O(V \cdot E)$。普通队列不保证「取出即最优」，点可能反复更新入队；在**网格图、菊花图**上会被卡到最坏（竞赛圈「关于 SPFA，它死了」的调侃即源于此）。

- **不可替代**：① **负权边**——Dijkstra 直接出局（贪心被负权打破），SPFA 是首选之一；② **判负环**——某点入队次数 ≥ V 即存在负权环，SPFA 顺手能做，Dijkstra 做不了。

## 2\.4 Dijkstra：贪心秒定型，代价是必须非负

Dijkstra 用优先队列「按 dist 从小到大弹出」，且每个点只处理一次。它的正确性可归结为一句关于松弛的断言：

**当从优先队列弹出 dist 最小的点 u 时，**$dist[u]$** 已是最终值，再不会被松弛变小。**

**证明只用一步**：任何还没定型的点 x 都有 $dist[x] \ge dist[u]$（u 是当前最小）；任何未来想改小 $dist[u]$ 的路径，都得经过某个未定型点再加一条 $\ge 0$ 的边，结果 $\ge dist[x] \ge dist[u]$，不可能更小。**「非负边」正是用在这一步**——它保证「绕一圈回来只会更贵」，松弛具有单调性，一旦定型永不反悔。

### 负边反例：亲手看 Dijkstra 翻车

```text
S->A = 1
S->B = 2
B->A = -2        (负边：从 B 到 A 反而省 2)
真实最短：S->B->A = 2 + (-2) = 0

Dijkstra 执行：
1. 弹出 S(0)，松弛得 A=1、B=2
2. 弹出最小的 A(1) -> 拍板 A=1，永久定型
3. 弹出 B(2)，尝试松弛 A = 2 + (-2) = 0 < 1……但 A 已定型，不回头 -> 错误留下 A=1
正确答案是 0。Dijkstra 输在「定型即永久」，而负边违背了这个前提。

```

**Dijkstra 可用性四条件自检**：① 最优子结构 ✓；② 非负边 ✓；③ 代价单调合并（$+w$ 不减）✓；④ 状态首次定型后不再变 ✓。四条齐了才敢用 Dijkstra；缺「非负边」就退回 Bellman\-Ford / SPFA。

## 2\.5 把三者放在同一根演进线上

|算法|松弛策略|顺序|负权|时间|
|---|---|---|---|---|
|**Bellman\-Ford**|每轮盲扫所有边|固定 V−1 轮|支持|$O(V \cdot E)$ 稳定|
|**SPFA**|只扩散「变化过」的点|FIFO 队列|支持|均摊常快，最坏 $O(V \cdot E)$|
|**Dijkstra**|贪心取全局最小|优先队列|不支持|$O(E \cdot \log V)$|

**两步优化，方向相反，别混为一谈：**

· **Bellman → SPFA 是「去冗余」**：不改变正确性边界（仍能负权），只是不再盲扫，改成事件驱动。

· **SPFA → Dijkstra 是「加贪心」**：用「非负权」假设换取「取出即定稿」，牺牲负权能力换来速度与稳定。

## 2\.6 更广的视角：边权规整度决定用哪把「锅」

把 Dijkstra 往「边权更规整」的方向退化，就得到 BFS 和 0\-1 BFS。三者本质是**同一个铁律**：label\-setting（确定即永久）要求你每次都能取出「当前全局最小的未定型距离」，只是按边权结构用了**刚好够用、最省**的那把锅。关键量是：**任意时刻，边界里同时存在的不同距离值，跨度有多大。**

|算法|边权|边界跨度|最省结构 \& 原理|
|---|---|---|---|
|**BFS**|全 = 1|2 档（k, k\+1）|FIFO 队列：均匀步长把排序变免费，「按层 = 按距离」|
|**0\-1 BFS**|∈ \{0,1\}|2 档 \+ 0 需插队|双端队列：0 边压队头、1 边压队尾，相当于「只有两个桶的排序器」|
|**Dijkstra**|≥ 0 任意|多档|优先队列（堆）：没有均匀步长帮忙，只能每次显式捞最小，$O(\log n)$|

**一条连续光谱**：BFS 和 0\-1 BFS 是 Dijkstra 在「边权极其规整」时的特例，规整到可以把 $O(\log n)$ 的堆降级成 $O(1)$ 的队列。**数据结构的差异，只是边权规整程度的「找零」。**

## 2\.7 边权为负时的完整武器库（速览）

一旦出现负边，label\-setting（Dijkstra 系）全线失效，只能退回 label\-correcting（反复修改），或先「洗」掉负边：

- **换算法（不改图）**：Bellman\-Ford（单源含负边，$O(VE)$，第 V 轮还降 = 有负环）；SPFA（稀疏图平均快）；DAG 拓扑 DP（图无环则负边照样对，$O(V+E)$）；Floyd\-Warshall（全源，$O(V^3)$）。

- **洗成非负再用 Dijkstra**：给每个点赋势能 $h(v)$，重定义 $w'(u,v)=w(u,v)+h(u)-h(v)$，使所有 $w' \ge 0$ 且最短路不变（势能沿路径首尾相消）。工业级实现即 **Johnson 算法**——一次 Bellman\-Ford 求势能 \+ 每源一次 Dijkstra。

- **伪负边从源头消掉**：整体平移（**仅当所有路径边数相同**，如分层图/恰好 k 步）；或把「奖励」改成 max\-plus 半环上求最长路，而非硬塞进最短路。

**负环是分水岭**：若存在「绕一圈总代价为负」的环，最短路会 $-\infty$、**无定义**。此时所有算法只能**检测并报告负环**（套汇里就是「发现无限套利」）——问题本身已病态，别再谈「最短」。

# 第三部分 · 本质联系：最短路就是动态规划

前两部分反复出现同一句话：所有解法都在解同一个 Bellman 方程，区别只在「遍历顺序 / 松弛策略」。这一部分把它推到底：**最短路和 DP 不是两个话题，而是同一个「不动点方程」的不同解法。**我们会以经典的「带约束最短路」为主线，串起升维、分层图、复杂度、以及「Dijkstra 是 DP 特例」这一贯通性结论。

## 3\.1 引子：为什么朴素 Dijkstra 会在「带约束最短路」上翻车

考虑一道典型题（LeetCode 787「K 站中转内最便宜的航班」）：求最短路，但**限制最多走 k 条边**。看到「最短路」第一反应是 Dijkstra 一把梭——但会错。

- **贪心不变量被打碎**：Dijkstra 假设「第一次弹出某点时其距离即全局最优」。但 K 约束下，最优性**不是一维的 dist，而是二维的 **$(dist,\ edges)$。

- **便宜 ≠ 更优**：一条现在更贵、但用边更少的路径，可能是通往终点的**唯一合法跳板**；Dijkstra 会因它当前「更贵」把它压在堆底，转头去锁死一条便宜却已耗尽跳数的**死路**。

**核心陷阱——升维 Dijkstra 误用一维 visited**：标准 visited 赌的是「一维最优，首次弹出即全局最优」。但本题到达一个城市有两个维度（花费 dist 和剩余预算 k），带不同 k 的两个状态**谁也不能剪掉谁**（「20 站前到」和「3 站前到」是两个独立状态）。补救靠**状态膨胀赎回正确性**：把 $visited[v]$ 换成 $visited[city][k]$，状态数从 n 膨胀到 $n \cdot k$（这也是复杂度里 $\log(n \cdot k)$ 的由来）。而 **DP 天生免疫**——$dp[1][A]$ 与 $dp[5][A]$ 各存各的，从不做贪心剪枝。

## 3\.2 关键一跃：给状态加一维，恢复无后效性

问题的病根是**有后效性**：原状态 $A$ 的未来取决于「我怎么到 A、还剩几站」——同一个 A 对应两个不同未来。而 DP 成立的唯一根基是**无后效性**（一个状态的未来只由状态本身决定）。手术方案：把作祟的历史变量（剩余预算）从「隐藏历史」提拔为「显式坐标」。

- 原始 Dijkstra 状态是一维 $v$（节点）。加 K 约束后，正确状态变成 $(v, k)$ = 「到达 v 且还剩 k 条边预算」。

- DP 状态 $dp[k][v]$ = 「用不超过 k 条边到 v 的最短距离」。**这两个状态空间是同一个东西**——在状态定义层面，升维 Dijkstra 与 DP 完全一致。

**升维 = 给状态空间加一根正交轴**，把原来重叠打架的局面沿新轴摊开，让每个局面独占一格。数学上就是笛卡尔积 $V_{new} = V_{原} \times \{\text{新维的所有取值}\}$：状态空间从一条线升成一张网格纸，$(A,5)$ 与 $(A,1)$ 各有唯一未来 → **无后效性恢复，DP 方程重新良定义**。

### 可复用方法论：加维的本质永远是消除有后效性

**当「当前节点的最优决策还偷偷取决于某个没写进状态的信息」时，把那个信息补进状态维度。**这是一把万能钥匙：

- 0/1 背包：光看「物品 i」不够，依赖「剩余容量」 → $dp[i][c]$；

- 带约束最短路：光看「城市 v」不够，依赖「剩余预算」 → $dp[v][k]$；

- 股票买卖：光看「第几天」不够，依赖「是否持仓」 → $dp[i][hold]$。

**每一个多出来的维度，都是一段「作祟的历史」被焊进状态、从而被驯服的痕迹。**

## 3\.3 分层图：把「环」抻直成「楼梯」

这里要破除一个流行误解：**状态转移图默认不是 DAG**。原图有环是常态（城市可来回飞，$A \to B \to A$ 完全合法），环 = 循环依赖 = 拓扑序不存在——这正是一维状态下不能简单平推、只能上 Dijkstra 或 Bellman 的原因。

升成 $(node, k)$ 后，来回飞变成：

```text
(A,k) -> (B,k-1) -> (A,k-2) -> (B,k-3) -> ...
第二坐标每步严格 -1，永远回不去。
回到 A 只能落在 (A,k-2)，那是另一个格子。

```

**分层图特殊在哪（三句话）**：① 不是「恰好是 DAG」，而是「被构造成 DAG」，特殊性来自那个**严格单调的维度**；② **单调维 = 现成的拓扑序**，层号 0,1,2… 就是拓扑排序结果，别的 DAG 要先跑拓扑排序，分层图**白送**；③ 正因顺序白送，Dijkstra 的堆变成可选项，平推 DP 更贴合结构。

贯通三层看这件事：

|层次|描述|
|---|---|
|表象|一个节点劈成一排，挨个推进|
|中层|隐藏历史变量（预算）升为显式坐标|
|**深层**|**消除有后效性 → 恢复「未来只由状态决定」→ DP 重新良定义**|

## 3\.4 「Dijkstra 是 DP 的特例」——全篇最值的一句

现在可以把前面所有线索收拢成一个贯通性结论。Dijkstra 和 DP **求解同一个 Bellman 方程，一字不差**；唯一分野是**求值顺序**：

|维度|Dijkstra|DP / Bellman|
|---|---|---|
|遍历维度的顺序|按 $dist$ 的**优先级序**（堆顶最小先弹）|按 $k$ 一层一层**推**（0→1→2…）|
|靠什么保证正确|贪心不变量：第一次弹出即最优|拓扑序：算 k 层时，k−1 层已全算完|
|取下一个状态的代价|堆挖最小，$O(\log)$，且要求非负权|拓扑序白送，$O(1)$|

**结论**：不是「升维后 Dijkstra 变得像 DP」，而是 **Dijkstra 本来就是 DP 的一个特例**——一个坚持用「最小代价优先」作为求值顺序、并因此要求边权非负的 DP 分支。它多付的 $\log$ 是为了在没有现成拓扑序的一般图里**动态挖顺序**；一旦拓扑序现成（如 K 这根轴白送），这个 $\log$ 是纯粹多付的「抽象税」，自然脱落。

由此推出一个实用判断：**分层图 Dijkstra 往往「多此一举」**。它先花力气把图整理成分层 DAG（等于承认顺序现成），又请堆来动态「发现」顺序——自相矛盾；且堆的「按 dist 最小优先」在 DAG 上毫无价值（任意拓扑序都正确）。把 $PriorityQueue$ 换成两层朴素 $for$，复杂度从 $O(k \cdot E \cdot \log)$ 干净落到 $O(k \cdot E)$ 无 log。

## 3\.5 复杂度是怎么「数」出来的（摊还方法论）

很多人算这类复杂度会算糊，根源是用了「每格 × 出度」的松散相乘。正确姿势是摊还。母公式：

$总时间 = (状态数) \times (单个状态的转移代价)$

- **数状态数**：$node$ 有 n 种，$edges$ 有约 k 种 → 状态数 $O(n \cdot k)$，这直接是**空间下界**（存整张表 $O(n \cdot k)$，滚动数组可压到 $O(n)$）。

- **数转移代价（关键技巧）**：别按「每格 × 平均出度」乘（会得到松散的 $O(n \cdot k \cdot n)$），而按「每条边被松弛几次」加总。

**关键恒等式：所有节点出度之和 = 边数 E**。固定某一层填满 = 把每条边恰好松弛一遍，代价 $\sum_{node} \deg(node) = E$；共 k 层，**总时间 = **$k \times E = O(k \cdot E)$。这就是为什么「每格看出度」零散乘会算糊，而「整层加起来」精确等于 E。

复杂度其实写在代码脸上——外层 k 轮、内层扫全部边 E，嵌套相乘就是 $k \times E$：

```java
for (int j = 1; j <= k; j++)          // <- k 层，贡献那个 k
    for ((u,v,w) : edges)             // <- 每层扫全部边 E，贡献那个 E
        relax(u -> v);

```

## 3\.6 平推 DP vs 滚动数组：同一算法的两种写法

发现「第 L 层只依赖 L−1 层」后，DP 有两种落地方式，区别**只在空间取舍**：

|写法|容器|时间|空间|额外能力|
|---|---|---|---|---|
|**平推 DP（二维表）**|$dp[layer][city]$ 整张表|$O(k \cdot E)$|$O(n \cdot k)$|可回溯路径 / 查任意层「恰好 j 条边」最优|
|**Bellman（滚动数组）**|$prev$/$cur$ 两行|$O(k \cdot E)$|$O(n)$** 最省**|只出最终答案|
|堆优化 Dijkstra|优先队列（膨胀状态）|$O(k \cdot E \cdot \log)$|$O(n \cdot k)$|——|

**两个易被误解的修正**：① 「遍历节点数一样」≠「时间复杂度一样」——状态数都是 $n \cdot k$，但单位代价不同（平推取下一个 $O(1)$，Dijkstra 每步多付 $O(\log)$ 维护堆）；② **时间和空间是两笔独立的账**——Bellman 滚动数组时间空间双优，但这是滚动数组的本事，不是「时间低自动推出空间低」。**选型**：只要最终答案 → 滚动数组；需回溯路径 / 查特定层最优 → 二维表。

## 3\.7 什么时候才能用「平推 DP / Bellman」——一条可背判据

不是所有带额外维的题都能平推。充要条件是：

**额外维度必须被「每一步转移」严格推进（单调消耗），中间不能有「原地不动、白走一步」的转移。**

破坏它的两种方式：**破法 A（非单调）**——维度既能增又能减，没有单调轴，无拓扑序；**破法 B（层内有环）**——存在「不消耗该维度」的转移，同一层内部能绕圈，那一层自己带环，不是 DAG。中招 A 或 B → Bellman 平推失效，须回到 Dijkstra（带权）或 BFS（单位权）。

|题目|额外维度|每步都严格消耗它吗|正确解法|能否 Bellman 平推|
|---|---|---|---|---|
|787 廉价航班|剩余中转数 k|是，每飞一趟必 −1|分层平推 DP|**适合，最优**|
|1928 限时最小花费|已用时间 t|是，每条边必 \+时间\(≥1\)|按时间平推 DP|**适合**|
|LCP 35 电动车游城市|电量 power|否，充电↑、行驶↓（**非单调**）|Dijkstra|不适合|
|864 获取所有钥匙|钥匙集合 mask|否，走格子不拿钥匙（**层内有环**）|BFS|不适合|
|1293 消除障碍最短路|剩余消除次数 k|否，走空格不消耗 k（**层内有环**）|BFS|不适合|

**一眼看穿的心法**：问自己「**我能不能在这个维度不变的情况下白走一步？**」——能，就有层内环，Bellman 失效（钥匙、消除次数、可充放的电量）；不能（每步都被迫消耗它，如中转数、时间），才轮到 Bellman/分层平推上场。

## 3\.8 再拔高一层：三种策略回答同一个问题

回到第二部分的四种调度，现在能用一句话统一它们了。解 Bellman 方程时的核心难题是「怎样避免无效松弛」，三种策略给出三种答案：

|策略|靠什么知道「谁会变、该松弛谁」|代表|
|---|---|---|
|**靠结构**|分层 DAG 静态地知道谁会变 → 按层推，连队列都不用（顺序已知的极致）|分层平推 DP（787）|
|**靠队列**|动态追踪谁刚变 → 事件驱动扩散（顺序未知的一般图）|SPFA|
|**靠贪心排序**|用「dist 最小优先」的贪心序保证有用，代价是必须非负权|Dijkstra|

**最终统一**：最短路与 DP 不只是「同一栋楼」——它们是**同一个不动点方程的不同解法**。数学上一句话概括整套理论：**在一个完备格上，对一个由半环决定的单调算子，求它的最小不动点 **$D^{*}=\operatorname{lfp}(F)$。序理论（Knaster–Tarski / Kleene）保证解存在且迭代能到，分析保证收敛，图论提供结构与顺序，代数（半环）决定「算的是什么」。

### 母公式与「换半环换算法」

所有这些算法共享一个骨架：$D^{*}=\operatorname{lfp}(F),\ F(D)=(A \otimes D) \oplus b$。其中 $\otimes$ 是「沿一条边把代价拼起来」（合成），$\oplus$ 是「多条路径汇到同一点时选一个」（聚合）。**换掉这对算子，就换出一个算法**：

|$\oplus$ 聚合|$\otimes$ 合成|得到什么|
|---|---|---|
|min|\+|最短路|
|max|\+|最长路 / 关键路径|
|\+|×|路径计数 / 概率|
|OR|AND|可达性 / 连通|
|min|max|最小瓶颈路|

可见「反复松弛到不再变化」在数学上就是**求单调算子的最小不动点**（第一部分那根「越勒越短的橡皮筋」= 单调升链在完备格中必有极限）；而 Bellman\-Ford 的逐轮迭代，正是 Kleene 升链 $\bot \le F(\bot) \le F^2(\bot) \le \cdots$ 的第 k 项——第 k 轮结束恰好等于「最多用 k 条边」的最短路，这与第二部分 Bellman\-Ford 的循环不变量**完全吻合**。

# 速记卡 · 十条核心结论

1. **两块砖**：状态（充分统计量，决定有几维）\+ 松弛（唯一原子动作，把估值单调压向真值）；收敛判据是三角不等式。

2. **三面墙 \+ 一面隐性墙**：无后效性（→DAG）、最优子结构、重复子问题；隐性第四面墙「非负边」决定能否秒定型。

3. **一根梁**：依赖（死板，被依赖方先定型）≠ 处理顺序（自由，可按代价跳）；解耦二者是程序不乱的秘密。

4. **没有几种算法，只有一个松弛 \+ 四种调度**：BF 全松弛 / SPFA 变化点 / Dijkstra 按 dist / DFS 记忆化，都在解同一个 Bellman 方程。

5. **Bellman\-Ford 的 snapshot 是灵魂**：冻结上一轮，严格保证每轮只放行一条新边；遍历所有边 = 穷举所有「最后一跳」= 无遗漏。

6. **SPFA = 聪明的 Bellman**，不是退化的 Dijkstra：抓松弛传染性、队列驱动、可负权可判负环，但最坏退化 $O(V \cdot E)$。

7. **Dijkstra 是 DP 的特例**：用「最小代价优先」作求值顺序、要求非负权的分支；拓扑序白送时，它的堆和 log 是多余的「抽象税」。

8. **带约束最短路第一原则**：约束（预算/时间/钥匙）必须写进状态维度；加维的本质是**消除有后效性**，恢复 DP 方程的良定义。

9. **能否用 Bellman 平推的判据**：「能不能在该维度不变时白走一步？」——能则层内成环（864、1293）或非单调（LCP 35），失效；不能（787、1928）才适用。

10. **复杂度靠摊还数出来**：$总时间 = 状态数 \times 单位代价$，$\sum \deg = E$ 得 $O(k \cdot E)$；状态数 $n \cdot k$ 定空间。最终统一于 $D^{*}=\operatorname{lfp}(F)$。
